# Counter Dashboard 🔢

A simple and modern Counter Dashboard built with Next.js, TypeScript, Tailwind CSS, and Zustand.

This project is created for practicing global state management using Zustand.

---

# 🚀 Features

- Add multiple counters
- Increment counter
- Decrement counter
- Reset single counter
- Reset all counters
- Show total sum of all counters
- Responsive UI
- Global state management with Zustand

---

# 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand

# 📦 Installation

Clone the project:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Go to the project folder:

```bash
cd counter-dashboard
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

# ⚙️ Zustand Store Overview

This project uses Zustand for global state management.

The store handles:

- Counter state
- Increment action
- Decrement action
- Add counter action
- Reset single counter
- Reset all counters
